# ЮРИСТ.КРД.23 — готовый комплект сайта

## Файлы
- `index.html` — главная страница.
- `style.css` — все стили, вынесены из HTML.
- `script.js` — модальное окно, форма, cookie-баннер и поведение блоков услуг.
- `policy/index.html` — страница политики обработки персональных данных.
- `thanks.html` — резервная страница благодарности.
- `1.png` — логотип/изображение из исходного сайта: оставьте существующий файл `1.png` в корне репозитория.

## Форма
Форма отправляется через FormSubmit на `yurist.krd.23@mail.ru`.
При первом реальном отправлении FormSubmit отправит на этот адрес письмо с подтверждением активации формы.
После подтверждения последующие заявки будут пересылаться на почту.

## Что уже сделано
- Первый CTA «Связаться с юристом» открывает форму вместо звонка.
- Поля формы: имя и телефон.
- Checkbox согласия на обработку персональных данных НЕ отмечен заранее и обязателен.
- Согласие на рассылку не добавлялось: в предоставленном согласии на ПД маркетинговая рассылка указана как отдельное согласие.
- Ссылка на политику видимая, контрастная, открывается в новой вкладке.
- Политика также есть в footer.
- Добавлены MAX, WhatsApp и Telegram.
- Все шесть разделов услуг раскрыты по умолчанию.
- Cookie-уведомление показывается при первом посещении и скрывается после нажатия «Понятно».
- В предоставленном исходном HTML не было обнаружено Яндекс.Метрики или Google Analytics.

ФОРМА: EMAILJS
1. Создайте аккаунт EmailJS.
2. Подключите почтовый сервис, на который должны приходить заявки (yurist.krd.23@mail.ru).
3. Создайте шаблон письма с переменными: name, phone, personal_data_consent.
4. В script.js замените YOUR_PUBLIC_KEY, YOUR_SERVICE_ID и YOUR_TEMPLATE_ID на значения из EmailJS.
5. Загрузите файлы на GitHub Pages.
6. При успешной отправке посетитель автоматически переходит на thanks.html.
